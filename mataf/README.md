# מתה״פ - מערכת תומכת החלטה פנסיונית

- `site/` - קוד המקור של האתר החי (גרסת 10:32, 10.11.2026). HTML/CSS/JS טהור,
  ללא שלב בנייה. שער הכניסה הוא `gate/_middleware.js` (Cloudflare Pages
  Function; הסודות מוזנים כמשתני סביבה בלוח הבקרה ואינם בקוד).
- `tests/` - חבילת הבדיקות של הגרסה (ראו `tests/tests-1032/RUN-ORDER.txt`).
- `requirements/` - דרישות, עיצוב והחלטות: `pension-planner-design-HE.md`
  הוא המסמך הראשי; `README-HE.md` מרכז כללי עבודה מתוארכים.
- `library/` - קוד המקור של ספריית המקורות (https://mataf-library.pages.dev):
  אתר סטטי שכל נכסיו מוצפנים ומפוענחים בדפדפן בלבד. פרטים ב־`README-SITE.md`.
  תיקיית `dist/` המוצפנת והחיה אינה כאן - היא תוצר פריסה.
- `knowledge/` - הידע הפנסיוני הנייד:
  - `recommendations/src/` - קוד מקור מצגת ההמלצות (React; רכיבי התצוגה
    מיובאים ממודול חיצוני בשם `@instinct/files` - לדוגמת מימוש מקומי פשוט
    ראו `tamam/src/components.tsx`).
  - `sources/` - קורפוס מקורות רשמי: תקנוני קרנות, מדריכי מס, מסמכי ממשק 009.
  - `mataf-knowledge-export-2026-11-09-consolidated-v4.md` - סיכום ידע מאוחד
    (מה אומת מול מקור רשמי ומה פתוח).

## הערת סמך

המערכת היא כלי עזר ואב־טיפוס; חלקים בה מסומנים כדחויים או לא־מאומתים במערכת
עצמה. אין לראות בתוכן ייעוץ פנסיוני או אישור מקצועי גורף.
