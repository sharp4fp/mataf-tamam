# אינדקס המקצוע - חבילת תוכן

profession-index.json: תוכן מובנה לאתר; profession-index-he.md: גרסה עברית מלאה; profession-index.csv: ייצוא פתוח.

זה אינדקס מערכתי של נושאי עבודה וסוגי ראיות נדרשות, לא מסמך שקובע חובות משפטיות מאומתות לכל פריט. שדות מקורות קשורים הם הצעות לבדיקה ברמת התחום ולא מיפוי סעיף מאושר. אין שיעור מוכנות מומצא.

לשילוב באתר הספרייה הקיים: אזור נפרד "מפת המקצוע", ניווט תחומים, חיפוש בנושאים ובמצב, הצגת רשימת בדיקות בכל נושא. לשמור במפורש גם נושאים ללא מסמכים. הורדתJSON/CSV/Markdown. אין להציג מספר מקורות כציון מוכנות. המצב של275והפקודה הוא "נמסר לפרסום" עד שיש אישור פרסום בפועל; לעדכן על סמך אישור כזה בלבד.

אין בחבילה פרטי לקוחות, סודות או תוכן ממאגר מסחרי.

גרסה1.1 מוסיפהcollection-manifest.json/CSVומקשרת כל תחום ונושא למשפחות מסמכים לאיסוף. זהו התוכן הסופי לשילוב ראשוני במקוםגרסה1.0.
