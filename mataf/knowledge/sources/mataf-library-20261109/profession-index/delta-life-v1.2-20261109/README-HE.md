# תוספת ביטוח חיים למפת המקצוע

תוספת ממוקדת לגרסה1.1:7נושאי ליבה ו4משפחות מקורות. בסך הכול28תחומים,175נושאים,62משפחות. יש להוסיף לתוכן האתר הנקי הקיים, לא לדרוס את תיקוני התצוגה/המקרא.

ביטוח חיים הוא תחום ליבה של סוכן פנסיוני במפה זו, לא רק תחום הפניה משלים; כל פעולה עדיין כפופה לסוג הרישיון, הסכם/מוצר ונתוני המקרה. ההבחנה בין פרמיה, הנחה ותנאי חיתום נשמרת.

המקורות החדשים הם יעדי איסוף, לא מסמכים שפורסמו או חובות שאומתו במלואן. אין כאן אישורAPI, תנאי הנחה או השוואת פוליסות אישית. חוזר החיים מסומן כמקור שנקרא בעבר ודורש קריאה מחדש לפני הסתמכות.
