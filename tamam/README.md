# תמ״מ - שטר מטען דיגיטלי (2276)

מערכת תמ״מ היא תוכנת ניהול למשאית מנוף העמסה עצמית של פיקאס בע״מ. הרכיב
הראשון שפותח הוא **שטר מטען דיגיטלי** בדוגמת שטר 2276 הנייר: הנהג ממלא את
השטר מהטלפון, בשטח, והלקוח חותם על אישור העבודה.

## מה יש כאן

- `src/App.tsx` - כל לוגיקת הטופס והממשק (React + TypeScript, הערות בעברית).
- `src/components.tsx` - רכיבי הממשק המקומיים (React סטנדרטי, בלי תלות חיצונית).
- `src/base.css`, `src/style.css` - עיצוב קומפקטי בדוגמת שטר הנייר + רקע עדין.
- `src/photos/` - תמונות הרקע והלוגו (רישיונות ב־`docs/CREDITS.md`).
- `docs/SPEC.md` - דרישות, החלטות עיצוב והתנהגות, כפי שהוסכמו בפיתוח.
- `docs/APPROVALS.md` - מה נכלל במראה הציבורית ומה הושמט במודע.
- `test/waybill-regression.mjs` - בדיקת רגרסיה אוטומטית (20 בדיקות, Playwright).

## הרצה מקומית

```bash
npm install
npm run dev        # שרת פיתוח
npm run build      # בנייה ל-dist
```

## בדיקת הרגרסיה

```bash
npm run build
npx vite preview --port 4517 &   # מגיש את הבנייה
npm test                          # מריץ 20 בדיקות מול הדף החי
```

הבדיקות מכסות: שני שדות השעה ריקים בכל פתיחה (גם אחרי רענון), מילוי שעת
הגעה רק בלחיצה או ידנית, חתימת לקוח שקובעת שעת סיום, ניקוי חתימה שמוחק את
שעת הסיום, הסתרת תצוגת השטר מאחורי כפתור, שמירה מקומית של שאר השדות,
ורשימת 14 הלקוחות.

## תכונות עיקריות

1. **בחירת לקוח** מרשימה שנלמדה משטרים היסטוריים, עם אפשרות לקוח חדש.
2. **פרטי עבודה**: תאריך, רכב (עם סוג מנוף ונהג ברירת מחדל לפי משאית), כתובת אתר, שעות.
3. **שעת הגעה לאתר** מתמלאת רק בלחיצה על "הגעתי עכשיו" או ידנית; עריכה ידנית מסומנת ונשמרת בהיסטוריה גם אם נדרסת מאוחר יותר.
4. **שעת סיום העבודה** נקבעת אוטומטית בחתימת הלקוח; ניקוי החתימה מוחק גם את שעת הסיום.
5. **שני שדות השעה ריקים בכל פתיחה של הטופס** - שום ערך שמור ממילוי קודם לא חוזר אוטומטית.
6. **חתימות**: נהג ולקוח (אישור עבודה) על ציר, במגע; אפשרות צילום/צירוף חותמת.
7. **תצוגת שטר מסודרת** מתעדכנת תוך כדי מילוי, מוסתרת כברירת מחדל ונפתחת מכפתור "הצג פרטי שטר דיגיטלי" בתחתית.
8. עיצוב נייד־ראשון (מובייל), רקע עדין של משאיות מנוף העמסה עצמית בעבודה.

## הערות פרטיות במראה הציבורית

- פרטי הקשר המלאים של החברה (כתובת, טלפון, דוא״ל) הושמטו מהכותרת התחתונה בגרסה זו; הם מופיעים בגרסה החיה.
- רשימת הלקוחות בקוד היא הרשימה האמיתית שאושרה לגרסה הפתוחה.
- שטרי המקור (PDF סרוקים, חתימות יד) אינם חלק מהמאגר.

## רישיון

הקוד והתכנים (למעט התמונות המצוינות ב־`docs/CREDITS.md`) שייכים לשרון סימון /
פיקאס בע״מ, כל הזכויות שמורות. מותר לקרוא, לנתח ולהציע שינויים; שימוש מסחרי
אחר דורש אישור בכתב.
