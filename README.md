# המאגר המשותף של שרון סימון / פיקאס בע״מ

מאגר ציבורי אחד עם שני פרויקטים נפרדים. המאגר נפתח לציבור ב־10 בנובמבר 2026
כדי לאפשר קריאה, שיתוף פעולה והתייעצות (למשל עם Claude או כלי AI אחרים).

## מבנה

- **`mataf/`** - מתה״פ: מערכת תומכת החלטה פנסיונית (עברית, RTL).
  - `mataf/site/` - קוד המקור המלא של האתר החי (HTML/CSS/JS טהור, ללא שלב בנייה).
  - `mataf/tests/` - חבילת הבדיקות של הגרסה החיה.
  - `mataf/requirements/` - מסמך הדרישות, העיצוב וההחלטות + כללי עבודה מתוארכים.
  - `mataf/library/` - קוד המקור של ספריית המקורות (אתר נפרד, תוכן מוצפן בצד־לקוח).
  - `mataf/knowledge/` - ידע פנסיוני נייד: קוד מקור ההמלצות, קורפוס מקורות רשמי
    (תקנונים, מדריכי מס, ממשק 009) וסיכום ידע מאוחד.
- **`tamam/`** - תמ״מ: תוכנת ניהול למשאית מנוף העמסה עצמית. הרכיב הראשון הוא
  שטר מטען דיגיטלי בדוגמת שטר 2276 הנייר. פרויקט React + TypeScript + Vite
  נייד וניתן להרצה - ראו `tamam/README.md`.

## עבודה עם Claude או כלי AI אחר

```bash
git clone https://github.com/sharp4fp/mataf-tamam.git
```

המאגר ציבורי וקריא לכל אחד בלי חשבון. נקודות כניסה מומלצות:
`mataf/requirements/pension-planner-design-HE.md` (דרישות מתה"פ),
`tamam/docs/SPEC.md` (דרישות תמ"מ), וכל שני תיקיית הקוד. להרצת תמ"מ מקומית:
`cd tamam && npm install && npm run dev`. שינויים מוצעים מתקבלים כ־Pull
Request או כטקסט מסודר.

## אתרים חיים

- מתה״פ (מוגן סיסמה): https://pension-planner-2br.pages.dev
- ספריית המקורות (מוגנת סיסמה): https://mataf-library.pages.dev

האתרים עצמם נשארים מוגני סיסמה; המאגר הזה חושף את קוד המקור בלבד.

## רישיונות

- קוד ותכנים (למעט המצוין): שרון סימון / פיקאס בע״מ, כל הזכויות שמורות.
  מותר לקרוא, לנתח ולהציע שינויים; שימוש מסחרי אחר דורש אישור בכתב.
- `mataf/site/` כולל את PDF.js ברישיון Apache 2.0 (נוסח ב־`LICENSE-Apache-2.0-PDFJS.txt`).
- תמונות הרקע של תמ״מ: Wikimedia Commons, לפי `tamam/docs/CREDITS.md`.
- מסמכי המקור הפנסיוניים ב־`mataf/knowledge/sources/` הם מסמכים רשמיים שפורסמו
  על ידי הגופים המנפיקים (מפקחת שוק ההון, רשות המסים, חברות הביטוח והמפעילות);
  הם מובאים כאן לצורכי עיון, והזכויות בהן שייכות למנפיקים.
